### Growth Intelligence for Startups

Thriven is a multi-tenant SaaS platform where startups sign up, log in, and track their own growth metrics — powered by an AI assistant that analyzes their specific data.

## Current Status
🚧 Active development — Phase 1 complete

## Tech Stack
- **Frontend:** React 19 + Tailwind CSS + shadcn/ui
- **Backend:** FastAPI + SQLite
- **Auth:** JWT + Google OAuth
- **AI:** Gemini API
